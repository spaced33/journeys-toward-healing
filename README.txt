Open index.html in a browser to preview the site.

EASY UPDATES
The file config.js contains the practice details that are most likely to change:
- email
- futureEmail (optional placeholder for a future domain-based address)
- phone
- psychologyToday
- headway
- alma
- villaHealth
- directScheduling

To activate an external profile button later, replace the empty URL with the full profile URL in config.js. The button will automatically change from “Coming soon” to “Visit my profile →”.

For a future business email, update the email field when the new address is ready. No HTML editing is required.

The site currently uses the business Gmail address and phone number provided for the practice. Psychology Today, Headway, Alma, and Villa Health are intentionally left inactive until the individual profile URLs are available.

The copy intentionally describes psychedelic-assisted therapy as training/background rather than advertising it as a service. Before publishing, review all clinical, licensure, privacy, telehealth, platform, and advertising language for your current jurisdiction and actual services.
